# Lifemap Task Organizer

Цей проєкт був створений на основі попереднього **Contact App**, але повністю перероблений під управління завданнями. Ідея полягала в тому, щоб перетворити список контактів у персональний органайзер із завданнями, інтегруючи сучасні функції, такі як сортування, фільтри та пріоритети.

## Історія створення

- Початково використовувався код Contact App для автентифікації та відображення елементів у вигляді списку.  
- Було створено нову базу даних Firestore для завдань (`tasks`) із полями:
  - **title** — назва завдання
  - **description** — опис
  - **dueDate** — дата дедлайну
  - **completed** — стан виконання
  - **userId** — користувач, який створив завдання
  - **priority** — пріоритет завдання (`high`, `medium`, `low`)
  - **category** — категорія завдання
  - **createdAt** та **updatedAt** — час створення та останнього редагування  
- Старі сторінки були адаптовані: замість контактів тепер завдання показуються у вигляді карток із можливістю відмічати виконані та видаляти завдання.  
- Додано сортування та пошук по назві, а також фільтр за виконаними і невиконаними завданнями.

## Основний функціонал

1. **Аутентифікація користувачів**  
   Firebase Auth забезпечує реєстрацію та вхід за e-mail. Сесії зберігаються і автоматично перенаправляють користувача на вкладку із завданнями.  

2. **Картки завдань**  
   - Відображають назву, опис, дедлайн, пріоритет та категорію.  
   - Можна відмічати виконані завдання прямо на картці.  
   - Кнопка видалення дозволяє безпосередньо видалити завдання з Firestore.  

3. **Сортування та фільтри**  
   - Сортування: за датою дедлайну або за назвою.  
   - Фільтр: виконані / невиконані.  
   - Пошук: за назвою завдання.  

4. **Пріоритети та категорії**  
   - Кожне завдання може мати пріоритет (`high`, `medium`, `low`) і категорію.  
   - Пріоритети відображаються різними кольорами для наочності.  

5. **Редагування та додавання завдань**  
   - Форма редагування дозволяє змінювати назву, опис, дедлайн, пріоритет та категорію.  
   - Нові завдання автоматично отримують `userId` і мітки часу.

## Технології

- **React Native**  
- **Expo Router**  
- **Firebase**: Auth та Firestore  
- **TypeScript** (опціонально)  
- **React Native Picker** для вибору пріоритету та категорії  

## Підсумок

Проєкт демонструє перетворення базового контактного додатку на повноцінний органайзер завдань із сучасним інтерфейсом та інтеграцією Firebase. Основна цінність — швидкий доступ до завдань, наочне відображення пріоритетів та категорій, гнучке сортування і фільтри.
